# 期末复习系统

一个在浏览器中运行的单文件复习工具。可以从复习资料中识别题目、建立多个题库、练习和重练错题，并查看练习统计。无需安装或构建项目。

> **版本信息：** `index.html` 开头注释标记为 v1.3，脚本中的 `APP_VERSION` 为 v1.3.1，内置更新日志最新一条为 2026-09-23 的 v1.3.2。三个字段目前不一致，发布时建议统一。

## 快速开始

1. 在浏览器中打开 `index.html`。
2. 选择题目文件，或在上传页粘贴题目文本。
3. 选择 AI 识别或本地识别。使用 AI 时，在「更改设置」中配置供应商、API 地址、模型和 API Key。
4. 检查识别预览；如有需要，打开题目详情编辑题干、选项或答案，再导入到新题库或已有题库。
5. 返回首页选择题库开始练习。建议定期使用「导出备份」保存题库数据。

## 支持的资料与识别方式

- 支持 `.docx`、`.xlsx`、`.xls`、`.pdf`、`.txt`、`.csv`，也支持粘贴纯文本；可一次选择多个文件。旧版 `.doc` 需先另存为 `.docx`。
- 自动识别单选、多选、判断、填空和简答题。识别结果可预览并逐题编辑；已有题库会跳过题干重复的题目。
- PDF 优先提取文字层；没有有效文字层时，会尝试在浏览器中使用中文 OCR。首次 OCR 需要联网加载相关程序和语言模型。
- 本地识别使用页面内规则处理题目，不需要配置 AI 模型。AI 识别可使用内置的 DeepSeek、阿里云百炼·通义、智谱 GLM、Kimi、豆包、腾讯混元、硅基流动、百度千帆、OpenAI、OpenRouter，也可填写自定义 OpenAI 兼容供应商。
- AI 识别需要有效的供应商 API Key 和网络连接。浏览器直连遇到 CORS 限制时，可尝试其他供应商，或在高级设置中填写自己的反向代理地址。
- 上传文件单个不超过 30 MB；PDF 最多 100 页。识别质量可能受原始文档排版和答案标注影响，导入前请核对题目与答案。

## 练习功能

- 可按题型练习，也可进行五种题型混合的综合测试。
- 支持顺序作答、乱序作答和看题模式；看题模式可通过题目目录跳转。
- 答题后即时反馈；简答题支持自评。答错的题会进入错题本，重练答对后自动移出。
- 作答结束后显示练习报告；首页记录正确率趋势、练习次数、平均正确率和最佳成绩。
- 桌面键盘可用 `←` / `→` 切题，数字键 `1`–`9` 跳题。
- 支持深色模式，以及完整、精简、关闭三档动效。

## 数据与隐私

- 题库、错题本、练习统计、界面主题和动效设置保存在当前浏览器的 `localStorage` 中；本项目没有自建后端。
- AI 设置中的 API Key 可选择是否记在当前浏览器。启用 AI 识别时，题目文本和 API 请求会发送到所选供应商，或发送到你自行填写的代理地址。请按供应商的隐私政策处理题目内容。
- 「导出备份」会下载 JSON 文件，包含题库、错题本和练习统计；「导入备份」会合并题库并处理重复题目。导入的备份文件不能超过 5 MB。
- 备份不包含 AI 配置、API Key、深色模式和动效设置；更换浏览器或清理浏览器数据前，请先导出题库备份，并重新配置 AI 设置。

## 运行依赖

应用主体由 HTML、CSS 和原生 JavaScript 构成，没有构建步骤。Tailwind CSS、Mammoth、SheetJS、pdf.js 和 tesseract.js 从 CDN 加载；文档解析及图片型 PDF OCR 需要网络访问相应资源。AI 识别还需要访问所选模型供应商。

完整更新记录可在应用内打开「更新日志」查看。
