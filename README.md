# 期末复习系统

一个纯前端、单文件的期末冲刺刷题工具。无需安装、无需后端、数据保存在本地浏览器 —— 双击即可打开使用。上传你的复习资料，AI 自动把题目识别成可练习的题库，然后按需刷题、错题重练、追踪正确率。

版本：`v1.3.1`
在线体验：<https://contr0l-text-review.netlify.app>

---

## 特性

### 智能题目识别
- 支持上传 `.docx` `.xlsx` `.xls` `.pdf` `.txt` `.csv`，也支持直接粘贴纯文本；旧版 `.doc` 请先另存为 `.docx`。
- **图片型 PDF 自动兜底 OCR**：PDF 取不到文字层时（扫描件、WPS「导出为图片」等），自动在页面内用 tesseract.js 逐页识别，无需先去别的工具转文字。
  - 双栏试卷自动按栏切分，不会把左右两栏串成一行；
  - 原卷里**黄底标出的正确答案**会自动转成「答案：X」，本地规则识别也能判成带答案的单选题；
  - 首次使用需联网下载中文模型（约 3.5 MB，之后走浏览器缓存）；59 页 / 660 题实测约 3 分钟跑完。
- 自动识别五种题型：单选题、多选题、判断题、填空题、简答题。
- AI 流式识别并**实时展示思考过程**；识别失败、未配置 Key 或遇到 CORS 限制时，自动回退到本地规则识别。
- 导入前可预览、逐题手动编辑、删除题目；自动去重。

### 多供应商 AI（OpenAI 兼容）
- 预置：DeepSeek、阿里云百炼·通义、智谱 GLM、月之暗面 Kimi、字节豆包、腾讯混元、硅基流动、百度千帆·文心、OpenAI、OpenRouter，以及自定义供应商。
- 全部使用官方品牌 Logo；支持一键获取供应商当前可用模型列表。
- API Key 仅保存在当前浏览器的 localStorage，直接发送给你选择的供应商接口，不经过任何中转。
- 内置各供应商 API 注册入口与新手接入教程链接。

### 灵活作答
- 顺序作答 / 乱序作答 / 看题模式三种方式；练习页顶栏可就地切换，看题模式支持题目目录跳转。
- 综合测试：五种题型混合，可乱序。
- 可横向滚动的跳题条（做对绿、做错红、当前放大）；键盘 `←` `→` 切题、数字键跳题（触屏设备自动隐藏快捷键提示）。
- 即时批改；简答题支持自评（我答对了 / 我答错了）。

### 错题本
- 答错的题自动收录进错题本；答对自动移出；支持一键清空。

### 报告与统计
- 作答报告：环形正确率、总题数、答对 / 答错、用时；满分触发彩带动画。
- 首页正确率趋势折线图：练习次数、平均正确率、最佳成绩（最多保留 200 条记录，备份导入导出均包含）。
- 一键重练本次错题、再来一遍。

### 数据管理
- JSON 备份导出 / 导入（支持合并与去重）。
- 支持多题库；一键重置数据。

### 界面与动效（v1.3）
- visionOS 质感：完整设计令牌 + 三层玻璃表面 + 发丝边 + 顶部内高光。
- 视图转场只作用于内容区并带前进 / 后退方向感；深色模式切换为圆形揭示转场。
- 三档动效开关（完整 / 精简 / 关闭），并自动尊重系统「减弱动态效果」。
- 练习页切题方向动画、分段控件滑动指示器、结果页弹性计数。

### 移动端适配（v1.3.1）
- 补齐刘海屏 / 底部 Home 指示条安全区（`viewport-fit=cover` + `safe-area-inset`），底部题号提示不再被遮挡。
- 练习页顶栏窄屏改为横向滑动不再换行；跳题条独占一行、圆点加大到 32px，手指好点。
- 触屏去掉双击缩放与点击延迟；输入框字号提到 16px（iOS 聚焦不再自动放大页面）；长公式 / 长单词自动换行不再撑破卡片。
- 窄屏关闭大面积固定背景、粘顶栏玻璃模糊降档、切题位移幅度减半，滚动与切题更跟手。
- 响应式：Windows / macOS / Android / iOS / 鸿蒙。

## 快速开始

1. 打开 **`index.html`**（推荐 Chrome / Edge / 手机浏览器），或直接访问 <https://contr0l-text-review.netlify.app>。
2. 首页点击「上传题库」，选择文件或粘贴文本。
3. 若使用 AI 识别：点击「更改设置」，选择供应商并填入自己的 API Key（首次可点「新手？查看接入教程」）。不配 Key 也能用「本地识别」。
4. 确认识别结果后导入，即可开始刷题。

> AI 识别与 OCR 都可能存在偏差，导入后请核对题目与答案。

## 已知限制

- **OCR 准确率约 90–95%**：题号被粘连、选项读残会导致少量题目缺失（660 题的 PDF 实测入库 632 题），个别字会认错（如「叙述」→「氢述」）。要更准请改用文字型 PDF / `.docx` / `.txt`。
- **图片型 PDF 的答案依赖黄底高亮**：原卷没有高亮标注答案时，导入的题目会缺答案。
- **AI 识别按 9000 字分段串行调用**：任一段失败会整份回退到本地规则识别（本地规则对 OCR 文本的题型判断不如 AI 准）。
- **首次 OCR 必须联网**（中文模型来自 jsdelivr），断网时只能用文字型文件。
- **极窄屏（≤320px）顶栏需要横滑一次**才能看到最右侧的模式按钮。
- 页面依赖 CDN（Tailwind / pdf.js / mammoth / SheetJS / tesseract.js），完全离线环境下上传解析不可用，已存题库仍可正常刷题。

## 技术栈

- 纯 HTML / CSS / JavaScript 单文件，无构建步骤。
- Tailwind CSS（样式）、mammoth（Word 解析）、SheetJS（Excel 解析）、pdf.js（PDF 解析与渲染）、tesseract.js + chi_sim 模型（图片型 PDF 兜底 OCR）。
- 题目、错题、统计等数据全部存储在浏览器 localStorage，无后端依赖。存储键：`final_review_system_data_v141`。

## 隐私说明

- 所有题库、错题、统计均保存在本地浏览器，不会上传到任何服务器。
